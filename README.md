# Pui la rotisor

Homepage statică pentru un magazin de pui la rotisor, kebab de pui și kebab de miel.

## Ce conține prototipul

- hero cu imagine de produs;
- meniu cu trei categorii;
- secțiune „Cum comanzi”;
- buton demonstrativ pentru comandă telefonică;
- buton pentru comandă online;
- dialog demonstrativ pentru profil/login;
- layout responsive pentru telefon și desktop.

## Ce urmează pentru o versiune reală

Pentru login, adrese salvate, comenzi și profiluri căutate după numărul de telefon ar fi nevoie de un backend, o bază de date și reguli de securitate pentru datele clienților.

În acest prototip, linkurile și datele de contact sunt demonstrative.
